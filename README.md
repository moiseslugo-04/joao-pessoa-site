# João Pessoa — Guia Turístico

Website turístico sobre João Pessoa, Paraíba, desenvolvido com HTML5, CSS3 e JavaScript puro.

O projeto apresenta alguns dos principais atrativos turísticos da cidade, com foco em praias, pontos turísticos e uma experiência visual moderna e responsiva.

## 📍 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma página web simples, moderna e responsiva para apresentar destinos turísticos de João Pessoa.

A proposta utiliza apenas tecnologias web fundamentais, sem frameworks ou bibliotecas externas, mantendo o projeto leve, organizado e fácil de compreender.

## ✨ Funcionalidades

- Página inicial com apresentação de João Pessoa
- Seção dedicada às principais praias
- Página com pontos turísticos
- Navegação entre as páginas
- Menu responsivo para dispositivos móveis
- Animações de entrada durante o scroll
- Botão para voltar ao topo
- Layout responsivo para diferentes tamanhos de tela
- Footer com ano atualizado automaticamente
